## ⚙️ Getting Started

### 1. Install Go

Download Go from the official website:

https://go.dev/dl/

Verify installation:

```bash
go version
```

### 2. Clone the Repository

```bash
git clone https://github.com/Udaykaran-Singh/Golang.git
```

### 3. Navigate to the Repository

```bash
cd Golang
```

### 4. Run a Program

Navigate to the respective topic directory and execute its Go file.

For example:

```bash
go run 1_hello_world/main.go
```

Another example:

```bash
go run 15_pointers/pointers.go
```
